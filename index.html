01

Tuzilma · poydevor

HTML nima va u nima uchun kerak?

Savol: What is HTML and why is it used in web development? Explain the basic structure of an HTML document.

HTML (HyperText Markup Language) — veb sahifaning skeleti. U brauzerga qaysi matn sarlavha, qaysi biri paragraf, rasm yoki havola ekanini bildiradi. HTML dasturlash tili emas, belgilash tilidir.

Har bir HTML hujjat odatda quyidagi asosiy qismlardan tuziladi:

index.html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <title>Mening birinchi sahifam</title>
  </head>
  <body>
    <h1>Salom, dunyo!</h1>
    <p>Bu mening veb sahifam.</p>
  </body>
</html>
✳Esda tuting: <head> sahifa haqidagi sozlamalarni saqlaydi; foydalanuvchi ko‘radigan kontent esa <body> ichida bo‘ladi.
02

Dizayn · ko‘rinish

CSS nima? Uni ulashning 3 usuli

Savol: What is CSS and what are the three ways to insert CSS into an HTML document?

CSS (Cascading Style Sheets) HTML elementlarining rangini, o‘lchamini, joylashuvini va boshqa ko‘rinishlarini belgilaydi. CSS’ni HTML hujjatga uch xil yo‘l bilan qo‘shish mumkin:

1. InlineUslub elementning o‘ziga yoziladi.style="color: red"
2. InternalCSS HTML faylining <head> qismida yoziladi.<style>…</style>
3. ExternalAlohida .css faylga yozib ulanadi.<link href="…" >

Amaliy loyihalarda ko‘pincha external CSS tanlanadi: HTML va dizayn alohida turadi, kodni yangilash va qayta ishlatish osonlashadi.

External CSS misoli
<!-- HTML fayl ichida: -->
<link rel="stylesheet" href="style.css">

/* style.css fayl ichida: */
body {
  background-color: #f4f7f4;
  font-family: Arial, sans-serif;
}
h1 { color: darkgreen; }
03

Elementlar · joylashuv

Block va inline elementlar farqi

Savol: What is the difference between a block-level element and an inline element? Give one short example for each.

Block element yangi qatordan boshlanadi va odatda mavjud kenglikni to‘liq egallaydi. Inline element esa matn oqimi ichida qoladi va faqat o‘z kontenti egallagan joyni oladi.

▰ Block — alohida qator

Masalan: <div>, <p>, <h1>

<p>Birinchi paragraf</p>
<p>Keyingi qator</p>

↔ Inline — matn ichida

Masalan: <span>, <a>, <strong>

<p>Bu <strong>muhim</strong>
so‘z matn ichida turibdi.</p>
✳Oddiy taqqoslash: block — yangi qatordagi quti; inline — shu qator ichidagi so‘zga o‘xshaydi.
04

Selektorlar · aniq nishon

CSS’da class va ID selektorlari

Savol: What is the difference between a class selector (.example) and an ID selector (#example)? When should you use each one?

Class ko‘p elementlarga bir xil uslub berish uchun ishlatiladi. CSS’da nuqta (.) bilan yoziladi. ID sahifadagi bitta noyob elementni nishonga oladi va CSS’da xesh (#) bilan yoziladi.

.class — qayta ishlatiladi

Bir nechta elementga bir xil ko‘rinish kerak bo‘lsa ishlating.

/* CSS */
.button { color: white; }

<!-- HTML -->
<button class="button">Saqlash</button>

#id — sahifada noyob

Bitta maxsus elementga murojaat qilish uchun ishlating.

/* CSS */
#main-title { color: darkgreen; }

<!-- HTML -->
<h1 id="main-title">
  Xush kelibsiz
</h1>
✳Yaxshi odat: takror ishlatiladigan dizaynlar uchun class tanlang. Har bir id HTML sahifada faqat bir marta ishlatilishi kerak.
